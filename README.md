# میکرو استودیو — سایت چندصفحه‌ای

سایت فارسی (RTL) با صفحه‌ی جدا برای هر اپ، خدمات، بلاگ، درباره‌ی ما و تماس. HTML/CSS/JS ثابت؛ بدون فریم‌ورک و بدون نیاز به سرور خاص.

## ساختار

```
index.html               خانه
products/                فهرست اپ‌ها + یک پوشه برای هر اپ (متن، ویدیو، گالری، نظر، پرسش‌ها)
services/  blog/  about/  contact/  404.html
style.css  script.js     استایل و منو/لایت‌باکس
assets/                  fonts، img (اسکرین‌شات)، icons، video (mp4 + poster)
tools/content.py         همه‌ی متن‌ها و داده‌ها (اپ‌ها، مقاله‌ها، خدمات)
tools/build.py           سازنده‌ی صفحه‌ها از روی content.py
```

## تغییر محتوا

متن را در `tools/content.py` عوض کنید و اجرا کنید: `python3 tools/build.py`
(خروجی HTML داخل مخزن نوشته می‌شود و commit می‌شود.) برای دیدن سایت: `python3 -m http.server`.

## قبل از انتشار

1. **دامنه:** `python3 tools/build.py --domain https://your-domain.ir` — canonical، og:url، og:image، sitemap.xml و داده‌ی ویدیو/اسکرین‌شات را اضافه می‌کند.
2. **آیکن‌ها و لوگو:** آیکن گوش‌یار واقعی است؛ بقیه‌ی `assets/icons/*.svg` و `favicon.svg` موقت‌اند. با همان نام فایل جایگزین کنید (اگر پسوند عوض شد، `icon` را در content.py تغییر دهید).
3. **پوپو:** پس از تأیید کافه‌بازار، `bazaar` و `status="live"` را در content.py بگذارید.
4. **هوهو علوم:** باز شدن لینک کافه‌بازار را بررسی کنید.
5. **نظرها:** نظر ساختگی نگذاشته‌ایم؛ صفحه‌ی هر اپ به نظرهای کافه‌بازار لینک می‌دهد. نظر واقعی و با اجازه را بعداً به content.py اضافه کنید.
6. **ادعاها:** «بدون تبلیغات مزاحم» و «بخش والدین قفل‌دار» را با نسخه‌ی منتشرشده تطبیق دهید. اسکرین‌شات‌ها را با اپ مربوط چک کنید.
7. **تماس:** فعلاً فقط اینستاگرام است؛ ایمیل/تلفن را در `page_contact` اضافه کنید.
