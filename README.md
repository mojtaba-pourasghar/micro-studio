# میکرو استودیو — قالب سایت

سایت تک‌صفحه‌ای فارسی (RTL) برای معرفی اپ‌ها و هدایت بازدیدکننده به کافه‌بازار. HTML + CSS + JS خالص، بدون فریم‌ورک و بدون بیلد.

## ساختار

```
index.html          صفحه + سئو (title، description، Open Graph) + داده‌ی ساختاریافته
style.css           همه‌ی استایل‌ها (نقاط شکست ۶۰۰، ۹۰۰، ۱۲۰۰)
script.js           منوی موبایل و نشان‌دادن بخش فعال
favicon.svg         نشان موقت
robots.txt
assets/fonts/       Vazirmatn (متغیر) و Poppins، محلی برای سرعت و دسترسی در ایران
assets/img/         اسکرین‌شات اپ‌ها (WebP)
assets/icons/       آیکن اپ‌ها
```

برای دیدن سایت: `python3 -m http.server` و باز کردن `http://localhost:8000`.

## آیکن‌ها

- آیکن واقعی گوش‌یار در `assets/icons/goshyar-*.webp` است.
- آیکن‌های `pashmak.svg`، `hoho-farsi.svg`، `hoho-math.svg`، `hoho-olom.svg` و `popo.svg` طرح موقت‌اند. آیکن واقعی هر اپ را با همان نام فایل جایگزین کنید (اگر PNG یا WebP بود، پسوند `src` را در `index.html` هم عوض کنید).
- لوگوی هدر و `favicon.svg` هم موقت‌اند تا فایل لوگوی نهایی جایگزین شود.

## قبل از انتشار

1. آدرس دامنه را بگذارید: `canonical`، `og:url`، `og:image` و `sitemap.xml` فعلاً نیستند چون دامنه مشخص نبود.
2. لینک پوپو (`com.pokpok.ir`) بعد از تأیید کافه‌بازار: دکمه‌ی «به‌زودی» را در کارت پوپو به `<a class="btn btn--purple" ...>` تبدیل کنید و پوپو را به `ItemList` داده‌ی ساختاریافته اضافه کنید.
3. بررسی کنید همه‌ی لینک‌های کافه‌بازار باز می‌شوند.

## رنگ هر محصول

گوش‌یار بنفش، پشمک نارنجی، هوهو فارسی سبزآبی، هوهو ریاضی زرد، هوهو علوم مرجانی، پوپو نیلی. رنگ‌ها در `style.css` (بخش `:root`) و روی هر کارت با `--c` تعریف شده‌اند.
