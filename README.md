# میکرو استودیو — صفحه‌ی اصلی

صفحه‌ی تک‌صفحه‌ای فارسی (RTL) برای معرفی استودیو و نمونه‌کارها. HTML + CSS + JS خالص، بدون فریم‌ورک و بدون بیلد.

```
index.html      کل صفحه
style.css       استایل
script.js       منو، نمایان‌شدن بخش‌ها، شمارنده، پخش ویدیو
assets/fonts    Vazirmatn + Poppins (محلی)
assets/art      هنر صحنه‌ی اول و شخصیت‌ها
assets/games    کاور نمونه‌کارها
assets/img      اسکرین‌شات‌های استفاده‌شده
assets/video    ویدیوی گوش‌یار (مودال)
```

دیدن سایت: `python3 -m http.server` و باز کردن `http://localhost:8000`.

## منبع تصویرها

کاور هر پروژه از مخزن خود آن پروژه برداشته شده است (`pilo/art_src`، `razino/assets/art`،
`goshyar_game/art`، `pokpok/docs` و …) و هنر صحنه‌ی اول، کی‌آرت «دو آسمان» است.
شخصیت‌ها با حذف پس‌زمینه از همان هنر اصلی بریده شده‌اند.

## قبل از انتشار

1. دامنه: `canonical`، `og:url`، `og:image` و `sitemap.xml` هنوز نیستند؛ بعد از مشخص‌شدن دامنه اضافه شوند.
2. وضعیت پروژه‌ها («در دست ساخت» / «کافه‌بازار» / «به‌زودی») را یک بار بازبینی کنید.
3. لینک کافه‌بازار هوهو علوم را امتحان کنید.
4. لوگو و `favicon.svg` هنوز طرح موقت‌اند.
5. نظر کاربران: هیچ نظر ساختگی نوشته نشده؛ بخش «والدین چه می‌گویند» به کافه‌بازار ارجاع می‌دهد.
