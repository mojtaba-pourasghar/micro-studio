## ۵. فرم‌های امضا (Signature Shapes)

- **دکمه با گوشه‌ی بریده** (`.btn`): برش `14px` در دو گوشه‌ی مقابل — مثل «LET'S TALK».
- **لبه‌ی مورب بخش‌ها:** `.notch-bottom` · `.notch-top` · `.notch-both`.
- **کارت با بریدگی پله‌ای** (`.notch-card`).
- **کارت خدمات و نظرات:** گوشه‌ی بریده‌ی `26–34px`.
- **دکمه‌ی پخش:** مربع گرد با یک گوشه‌ی تیزتر (`26px 26px 26px 8px`) + گرادیان بنفش + حلقه‌ی پالس.
- **دکمه‌ی گرد «شروع پروژه»:** دایره‌ی شیشه‌ای با حلقه‌ی خط‌چین چرخان.

## ۷. موشن و افکت‌ها (HTML5)

همه در `assets/js/motion.js` قرار دارند و با **data-attribute** یا کلاس کنترل می‌شوند:

| Attribute / کلاس | افکت |
|---|---|
| `data-split` | تیتر به کلمه‌ها شکسته می‌شود؛ هر کلمه یک‌درمیان از چپ و راست با بلور و چرخش می‌آید و سر جایش جمع می‌شود |
| `.reveal` + `.from-right` / `.from-left` / `.from-top` / `.zoom` / `.blur` | ورود از جهت‌های مختلف، زوم با چرخش، فید از حالت بلور |
| `.reveal-up` | بالا آمدن همراه با کمی بزرگ‌شدن |
| `.stagger` | فرزندان یکی‌یکی وارد می‌شوند (کارت‌ها، ردیف‌ها، گالری) |
| `.wipe` | تصویر با برش مورب (clip-path) باز می‌شود و زوم‌اوت می‌کند |
| `data-speed="-0.3"` | پارالاکس عمودی هنگام اسکرول |
| `data-x="160"` | کاراکتر از کنار صفحه وارد می‌شود و با اسکرول سر جایش می‌نشیند |
| `data-rot="20"` | چرخش با اسکرول (جم‌ها، دایره‌ی جادوگر) |
| `data-sx="-180"` | جابه‌جایی افقی کلمه‌های بزرگ (MICRO) با اسکرول |
| `data-depth="1.6"` | دنبال‌کردن حرکت موس (عمق سه‌بعدی) |
| `data-magnetic` | دکمه به سمت کرسر کشیده می‌شود |
| `data-parallax` | پارالاکس پس‌زمینه‌ها (در main.js) |
| `data-count` | شمارنده‌ی اعداد فارسی |
| کرسر سفارشی | نقطه + حلقه؛ روی لینک بزرگ می‌شود و روی فیلد متن به خط عمودی تبدیل می‌شود |
| تیلت سه‌بعدی | کارت‌های نمونه‌کار، خدمات و نظرات + نور براق دنبال موس |
| پرده‌ی ورود | لوگوی چرخان + نوار بارگذاری؛ سپس پرده بالا می‌رود |
| نوار پیشرفت اسکرول | خط گرادیان بالای صفحه |
| Ken Burns + ذرات | زوم آهسته‌ی پس‌زمینه‌ی Hero و ذرات نورانی شناور |

**مدت‌ها:** `--t-fast .18s` · `--t-med .32s` · `--t-slow .8s` · easing: `cubic-bezier(.22,1,.36,1)`

**قواعد موشن:**
- `prefers-reduced-motion` ← همه‌ی انیمیشن‌ها، کرسر و پرده خاموش می‌شوند و محتوا فوراً نمایش داده می‌شود.
- دستگاه لمسی ← فقط افکت‌های اسکرول با شدت ۴۵٪؛ کرسر، تیلت و دکمه‌ی مغناطیسی غیرفعال‌اند.
- اگر IntersectionObserver دیر عمل کند، یک بررسی پشتیبان بر اساس موقعیت عنصر، محتوا را نمایش می‌دهد.

## ۸. دسترس‌پذیری

- لینک «رفتن به محتوای اصلی»، حلقه‌ی فوکوس بنفش (`:focus-visible`)، هدف لمسی حداقل `44px`.
- منوی موبایل با `aria-expanded`؛ بستن با Esc و کلیک بیرون.
- لایت‌باکس ویدیو با تله‌ی فوکوس.
- تیترهای شکسته‌شده `aria-label` کامل دارند.
- تصاویر تزئینی `alt=""`؛ تصاویر محتوایی `alt` فارسی.

## ۱۱. قوانین طراحی صفحات بعدی

1. هدر، فوتر، اسپرایت آیکن SVG، پرده‌ی ورود، کرسر و نوار پیشرفت **عیناً** از `index.html` کپی شوند.
2. هر صفحه یک Hero کوتاه‌تر (`min-height: 60svh`) با تیتر `data-split` و مسیر (Breadcrumb) داشته باشد.
3. بخش‌های روشن (`--paper`) و تیره (`--night`) یک‌درمیان، با لبه‌ی مورب `.notch-*`.
4. الگوی هر بخش: `.eyebrow` + `.h2[data-split]` + `.lead.reveal.blur` + `.btn-primary[data-magnetic]`.
5. در هر بخش حداقل یک کاراکتر با `data-x` + `data-speed` + `data-depth`.
6. در منو `aria-current="page"` روی صفحه‌ی جاری.
7. فقط از رنگ‌های بخش ۲ استفاده شود.
8. قبل از تحویل: تست در ۱۴۴۰، ۸۲۰، ۳۹۰ و ۳۷۵ پیکسل و در حالت reduced-motion.

## ۱۳. صفحه‌ی تکی بازی/اپ — `game-single.html`

یک صفحه‌ی **نماینده** برای همه‌ی ۹ محصول (دیتای نمونه: رازینو). بعداً در PHP مثلاً با `game.php?slug=razino` از دیتابیس خوانده می‌شود؛ یک قالب برای همه.

**قرارداد قالب:**
- `data-field="نام_ستون"` ← مقدار از جدول `games` جایگزین می‌شود.
- `data-repeat="نام_جدول"` ← فرزندانِ این عنصر حلقه‌ای روی جدول فرزند هستند (اولین فرزند الگوی هر ردیف است).
- کلاس‌ها و attributeهای افکت (`data-split`، `reveal`، `stagger`، `data-x`، ...) بدون تغییر می‌مانند.

### ۱۴-۳. ساختار پیشنهادی دیتابیس

```sql
CREATE TABLE post_categories (id INT AUTO_INCREMENT PRIMARY KEY, slug VARCHAR(40) UNIQUE, name VARCHAR(60), sort_order INT);
CREATE TABLE posts (
  id INT AUTO_INCREMENT PRIMARY KEY,
  slug VARCHAR(120) UNIQUE NOT NULL,
  category_id INT REFERENCES post_categories(id),
  game_id INT NULL REFERENCES games(id),          -- کارت «بازی این مطلب» در ستون کناری
  title VARCHAR(200) NOT NULL,
  excerpt TEXT,                                    -- خلاصه‌ی کارت و meta description
  cover_image VARCHAR(255),
  body_html MEDIUMTEXT,                            -- پاک‌سازی‌شده
  author VARCHAR(80), author_bio VARCHAR(255), author_avatar VARCHAR(255),
  read_minutes TINYINT,                            -- یا محاسبه از تعداد کلمات (~۲۰۰ کلمه در دقیقه)
  is_featured TINYINT(1) DEFAULT 0,
  status ENUM('draft','published') DEFAULT 'draft',
  published_at DATETIME
);
CREATE TABLE post_tags (post_id INT, tag VARCHAR(40), PRIMARY KEY (post_id, tag));
CREATE TABLE subscribers (id INT AUTO_INCREMENT PRIMARY KEY, email VARCHAR(190) UNIQUE, created_at DATETIME, confirmed TINYINT(1) DEFAULT 0);
```

- **تاریخ:** در دیتابیس میلادی (`DATETIME`) ذخیره شود؛ در `<time datetime="2026-11-10">` میلادی و متن نمایشی شمسی با `IntlDateFormatter` (`fa_IR@calendar=persian`).
- **سئو:** برای `post.php` تگ‌های `og:title`، `og:image` و JSON-LD نوع `BlogPosting` اضافه شود.
